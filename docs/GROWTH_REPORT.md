## How to keep this honest and easy
- Every user number traces to a form response and, ideally, an on-chain transaction you can link.
- Every "improvement" traces to a real git commit link.
- Screenshots come from the real Vercel Analytics dashboard and the live app, not mockups.
- If a level asks for something you have not genuinely done yet (mainnet, an audit, 50 real
  users), do the real thing first. A rejected honest submission beats a banned fake one.
